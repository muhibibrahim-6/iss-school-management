
# ISS School Management

A school management platform by International System Security (ISS).

## Planned portals
- ISS Owner
- School Admin
- Teacher
- Student
- Parent

## Core features
- School and user management
- Student records
- Attendance
- Timetable
- Exams and results
- Manual fee records
- Reports
- School branding
- Responsive dashboard

## Technology
- React and TypeScript
- Node.js and Express
- PostgreSQL
- Prisma ORM

## Setup status
This repository is under development.
The database schema and initial API are starter components.

Before production use, implement and test:
- Secure authentication
- Server-side role authorization
- School data isolation
- Password reset
- Audit logs
- Backups and recovery

Never use real student information in a public demo.
Never commit secrets or production credentials.
